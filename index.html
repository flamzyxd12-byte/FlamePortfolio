About

I like making things for the web.

I got into web development because I enjoy the mix of logic and design. There is something satisfying about writing code and seeing a real interface come together on screen.

These days I spend most of my time building with React, Tailwind CSS, and plain JavaScript. I care about responsive design, clean code, and small details that make a site feel polished.

When I am not working on projects, I am usually learning something new — whether that is a CSS technique I have not tried, a React pattern, or just improving how I structure my code.
