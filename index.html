My Journey

How I got to where I am

Phase 01

Learning the Fundamentals

Started my journey by mastering semantic HTML5 and clean CSS layouts. Focused heavily on building accessible, well-structured web pages from scratch.

Phase 02

Diving deep into JavaScript

Moved into logic and programming paradigms. Focused on asynchronous JavaScript, DOM manipulation, APIs, and writing clean, reusable scripts.

Phase 03

Building Scalable UI with React

Stepped into modern component-based frameworks. Mastered state management, component lifecycles, hooks, and single-page architectures using React and Next.js.

Phase 04

Expanding into Backend Development

Began building custom backend layers using Node.js and Express. Learned how to design databases, manage user authentication, and create secure REST APIs.
