Process

How I work

01 — Understand

Figure out what the website needs

I start by understanding the goal. What should the site do? Who is it for? What matters most?

02 — Build

Turn the idea into a responsive interface

I write clean, structured code and focus on making the layout work well on every screen size.

03 — Refine
